# Does-higher-instability-imply-higher-collision-risk-Evidence-from-the-AstaZero-dataset
Codes for the paper 'Does higher instability imply higher collision risk? Evidence from the AstaZero dataset'.
The data sources can be downloaded from 'https://data.jrc.ec.europa.eu/dataset/9702c950-c80f-4d2f-982f-44d06ea0009f'

1. calibration.py is for calibrating CF models;
2. calibrated_cf_params.py is for storing calibrated CF parameters;
3. simulation.py is for running simulations. The details of simulation settings are in the paper;
4. simulation_analysis.py is for analyzing the data collected from simulations and field data;
5. visualization_field is for visualizing the field data.
